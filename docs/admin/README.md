# Admin Policy Documentation (Finance & Logistics)

This folder contains admin guides for **Finance** and **Logistics** policies. Each doc explains how to create policies, where they are used, and what each option affects.

## Finance

| Doc | Description |
|-----|-------------|
| [ADMIN_FINANCE_PAYMENT_POLICIES.md](./ADMIN_FINANCE_PAYMENT_POLICIES.md) | Payment rules: advance amount, escrow, grace period, vendor types, service location. |
| [ADMIN_FINANCE_REFUND_POLICIES.md](./ADMIN_FINANCE_REFUND_POLICIES.md) | Refund tiers: hours before service, refund %, cancellation fee, vendor types, service location. |
| [ADMIN_FINANCE_CANCELLATION_POLICY.md](./ADMIN_FINANCE_CANCELLATION_POLICY.md) | Cancellation policy: windows, grace period, vendor penalty, no-show. |
| [ADMIN_FINANCE_GST_CONFIGURATION.md](./ADMIN_FINANCE_GST_CONFIGURATION.md) | GST configuration: HSN codes, tax categories, CGST/SGST/IGST rates. |
| [ADMIN_FINANCE_FLEXIBLE_TAX_SYSTEM.md](./ADMIN_FINANCE_FLEXIBLE_TAX_SYSTEM.md) | Flexible tax rules: tax type, rate, priority, conditions, exemptions. |
| [ADMIN_FINANCE_SETTLEMENTS.md](./ADMIN_FINANCE_SETTLEMENTS.md) | Settlements dashboard: vendor payables, Due/Pending/Paid, Process. |
| [ADMIN_FINANCE_PAYOUT_MANAGEMENT.md](./ADMIN_FINANCE_PAYOUT_MANAGEMENT.md) | Payout management: review, Process/Reject, Export, vendor bank. |
| [ADMIN_FINANCE_TIER_SYSTEM.md](./ADMIN_FINANCE_TIER_SYSTEM.md) | Tier system: commission rate, payout period, subscription cost, roles. |
| [ADMIN_FINANCE_SCHEDULE_SETTINGS.md](./ADMIN_FINANCE_SCHEDULE_SETTINGS.md) | Schedule settings: when settlements run, period, auto-process, Process Now. |
| [ADMIN_FINANCE_SETTLEMENT_RULES.md](./ADMIN_FINANCE_SETTLEMENT_RULES.md) | Settlement rules: conditions (tier, category, amount), period, commission, hold. |
| [ADMIN_FINANCE_PAYMENT_GATEWAY.md](./ADMIN_FINANCE_PAYMENT_GATEWAY.md) | Payment gateway: gateways, Payment Rules, Refund Policies, Schedule. |

## In-app Help

In the Admin UI, each of these screens has a **Help** (?) button next to the title. Clicking it opens a dialog with this documentation so admins can read the guide without leaving the page.

- **Finance & Logistics**: Payment Policies, Refund Policies, Cancellation Policy, GST Configuration, Flexible Tax System, Settlements, Payout Management, Tier System, Schedule Settings, Settlement Rules, Payment Gateway
- **Platform Settings → Integrations → Logistics**: Partners & Configuration, Delivery Rules
