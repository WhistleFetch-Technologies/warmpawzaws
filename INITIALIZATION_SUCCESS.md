## 🐛 Quick Troubleshooting

### Metro Bundler Issues
```bash
npm start -- --reset-cache
```

### Android Build Issues
```bash
cd android
./gradlew clean
cd ..
npm run android
```

### Port Already in Use
```bash
lsof -ti:8081 | xargs kill -9
npm start
```

### iOS Pod Issues
```bash
cd ios
pod install
cd ..
npm run ios
```
