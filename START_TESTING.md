## 🐛 If Something Goes Wrong

### Red Screen Error
- Check Metro bundler terminal
- Look for error messages
- Try: `npm start -- --reset-cache`

### Build Fails
- Check Android Studio is installed
- Check Android SDK is configured
- Try: `cd android && ./gradlew clean && cd .. && npm run android`

### App Won't Launch
- Check emulator/device is running
- Check USB debugging enabled (physical device)
- Restart Metro bundler
