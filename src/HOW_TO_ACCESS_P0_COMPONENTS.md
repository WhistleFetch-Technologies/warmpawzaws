## 📍 STEP-BY-STEP ACCESS GUIDE

## 📊 WHAT EACH COMPONENT DOES

### 1. 📈 Analytics Dashboard
**What it shows:**
- 8 KPI cards (GMV, Revenue, Customers, Vendors, Bookings, Orders, AOV, Conversion)
- Revenue trend charts
- Category distribution pie chart
- Vendor performance analytics
- Tabbed views (Overview, Revenue, Vendors, Customers)

**How to use:**
1. Click "Analytics Dashboard"
2. View KPIs at top
3. Switch between tabs for different views
4. Change date range (top-right dropdown)
5. Click "Export" to download data

---

### 2. 💳 Payment Gateways
**What it shows:**
- List of configured payment gateways (Razorpay, Stripe, PayPal, Paytm)
- Gateway configuration panels
- API key management
- Test/Live mode toggle
- Webhook settings

**How to use:**
1. Click "Payment Gateways"
2. Select a gateway from left sidebar
3. Click "Edit Mode" (top-right)
4. Update settings
5. Click "Test Connection"
6. Save changes

---

### 3. 🧾 Payout Management
**What it shows:**
- Pending payouts table
- Processing payouts
- Completed payouts
- Vendor bank details
- Commission breakdown
- TDS calculations

**How to use:**
1. Click "Payout Management"
2. Filter by status (Pending/Processing/Completed)
3. Click "View Details" on any payout
4. Review vendor & bank info
5. Click "Approve" or "Reject"
6. For processing payouts, click "Complete"

---

### 4. 🏷️ Coupon Management
**What it shows:**
- Grid of all coupons
- Coupon stats (Total, Active, Uses, Discount Given)
- Search and filters
- Usage tracking

**How to use:**
1. Click "Coupon Management"
2. Click "Create Coupon" (top-right)
3. Fill in details (or click "Generate" for auto code)
4. Set discount type and value
5. Set date range
6. Toggle "Active"
7. Click "Create"

---

### 5. 🔄 Returns & Refunds
**What it shows:**
- Return request list
- Product details with images
- Customer reasons
- Status tracking
- Refund processing

**How to use:**
1. Click "Returns & Refunds"
2. Filter by status
3. Click "View Details" on any return
4. Review customer reason
5. Click "Approve" or "Reject"
6. For approved returns, click "Process Refund"

---

### 6. 💬 Support Tickets
**What it shows:**
- Ticket list with priorities
- Conversation threads
- Status badges
- Response time tracking
- Customer details

**How to use:**
1. Click "Support Tickets"
2. Click any ticket to open
3. Read conversation
4. Type reply in text area
5. Click "Send Reply"
6. Update status (Open → In Progress → Resolved)

---

### 7. ⚡ Promotions Engine
**What it shows:**
- Promotion cards with analytics
- Promotion types (Flash Sale, Buy X Get Y, Bundle, etc.)
- Analytics per promotion
- Stackable promotions
- Priority ordering

**How to use:**
1. Click "Promotions Engine"
2. Click "Create Promotion" (top-right)
3. Select promotion type
4. Set discount value
5. Set date range
6. Configure target audience
7. Toggle "Active"
8. Click "Create"

### Issue: Component not loading
**Solution:** Check browser console for errors, refresh page
