## 🔧 HOW TO USE

### 1. Seed (One-time)
Call the API endpoint above

### 2. Verify
Go to **Platform Admin** → **Catalog & Services** → **Services**

### 3. Vendors Enable Services
Vendors go to **Service Management** → Select services to enable

### 4. Customers Book
Services automatically appear in customer search/booking
