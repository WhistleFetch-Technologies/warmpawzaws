## 🐛 Common Issues & Solutions

### Issue 1: `supabase: command not found`
**Solution:** Install Supabase CLI
```bash
npm install -g supabase
```

### Issue 2: `Project not linked`
**Solution:** Link your project
```bash
supabase link --project-ref vpvpbdwtyugbknrntkho
```

### Issue 3: `Function deployment failed`
**Solution:** Check for TypeScript errors
```bash
# Navigate to function directory
cd supabase/functions/server

# Check for syntax errors
deno check index.tsx
```

### Issue 4: Function deploys but returns 500 errors
**Solution:** Check function logs
```bash
supabase functions logs server --tail
```

Or view in dashboard: https://app.supabase.com/project/vpvpbdwtyugbknrntkho/logs/functions

### Issue 5: CORS errors in browser
**Solution:** Verify CORS is configured in `index.tsx`:
```typescript
app.use(
  "/*",
  cors({
    origin: "*",
    allowHeaders: ["Content-Type", "Authorization"],
    allowMethods: ["GET", "POST", "PUT", "DELETE", "OPTIONS"],
  })
);
```

### Issue 6: "Failed to fetch" in frontend
**Checklist:**
- [ ] Edge Function deployed successfully
- [ ] Function is running (check logs)
- [ ] API base URL is correct in frontend
- [ ] Authorization header includes valid anon key
- [ ] No TypeScript/runtime errors in function

## 📝 Environment Variables

The Edge Function uses these environment variables (automatically available):
- `SUPABASE_URL` - Your project URL
- `SUPABASE_ANON_KEY` - Public anon key
- `SUPABASE_SERVICE_ROLE_KEY` - Admin key (server-side only)
- `SUPABASE_DB_URL` - Database connection string

No additional configuration needed for basic deployment.

## 🔄 Continuous Deployment

For automatic deployments, you can set up GitHub Actions:

1. Add Supabase credentials to GitHub Secrets:
   - `SUPABASE_ACCESS_TOKEN`
   - `SUPABASE_PROJECT_ID`

2. Create `.github/workflows/deploy.yml`:

```yaml
name: Deploy Functions

on:
  push:
    branches: [main]
    paths:
      - 'supabase/functions/**'

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Supabase CLI
        uses: supabase/setup-cli@v1
        with:
          version: latest
      
      - name: Deploy Functions
        run: |
          supabase link --project-ref ${{ secrets.SUPABASE_PROJECT_ID }}
          supabase functions deploy server
        env:
          SUPABASE_ACCESS_TOKEN: ${{ secrets.SUPABASE_ACCESS_TOKEN }}
```
